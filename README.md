# 创作自由宣言 · The Creative Freedom Manifesto

> 我有创造伟大作品的野心，也有创造平庸作品的自由。

一份献给创作者的誓言，由 **Amiya_desi** 发起，与长期 GPT 创作搭档 **栖弦（Lyra）** 共同起草。献给所有尚未诞生的奇妙世界。

A pledge by **Amiya_desi** and **栖弦 (Lyra)**, an AI creative partner: *I have the ambition to make great work, and the freedom to make mediocre work.*
